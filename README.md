# AlphaVision

Site de hipercarros e superesportivos (TCC).

## Como abrir
Dê dois cliques em `index.html`. Precisa de internet só para carregar as fontes.

## Páginas
- `index.html` – início
- `veiculos.html` – coleção, filtro, detalhes e reserva
- `empresa.html` – a empresa
- `financeiro.html` – financiamento e simulador
- `colaboracao.html` – parcerias com marcas

## Pastas
- `assets/` – fotos dos carros
- `css/maison.css` – visual
- `js/site.js` – menu, reserva e simulador

A reserva fica salva no navegador. Ao confirmar, abre o WhatsApp com o resumo.

Para o botão de WhatsApp funcionar, coloque o número do agente na primeira linha de `js/site.js` (`WHATSAPP`).
